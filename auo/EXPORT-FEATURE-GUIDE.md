# 📊 匯出報表功能說明

## 功能概述

AI 流程改善獎勵機制系統現在支援**真實的匯出報表功能**，可以將提案數據匯出為兩種格式：

---

## 🎯 支援的匯出格式

### 1️⃣ Excel (CSV) 格式
**適用場景**：數據分析、進一步處理

#### 匯出內容包括：
- 提案編號
- 提案標題
- 提案人
- 部門
- 提交日期
- 使用工具
- 改善前狀況
- 改善後方案
- 節省效益描述
- 節省時間（分鐘）
- 狀態（待審核/已通過/已退回）
- 等級（Level 1/2/3）
- 創新度評分
- 推廣性評分
- 效益性評分
- 總分
- 獎勵金額

#### 特色：
✅ 支援中文編碼（UTF-8 with BOM）
✅ 可在 Excel 或 Google Sheets 直接開啟
✅ 適合製作樞紐分析表
✅ 方便進行統計分析

#### 檔案命名：
```
AI流程改善提案報表_2024-12-04.csv
```

---

### 2️⃣ 完整報告 (HTML) 格式
**適用場景**：報告呈現、列印、分享

#### 包含內容：
**📈 統計儀表板**
- 總提案數
- 待審核數量
- 已通過數量
- 已發獎勵金總額

**📋 提案詳細清單**
- 所有提案的完整資訊表格
- 狀態標籤（彩色區分）
- 等級徽章
- 獎勵金額

**📊 已通過提案詳情**
- 改善前後對比
- 詳細評分（創新、推廣、效益）
- 獎勵金明細

#### 特色：
✅ 精美的視覺設計
✅ 支援直接列印
✅ 響應式排版
✅ 可在瀏覽器直接查看
✅ 適合向主管報告

#### 檔案命名：
```
AI流程改善提案報表_2024-12-04.html
```

---

## 🚀 使用方式

### 步驟 1：進入審核儀表板
在側邊欄點擊「審核儀表板」

### 步驟 2：點擊匯出按鈕
在右上角找到「匯出報表」按鈕（藍色按鈕，有下載圖示）

### 步驟 3：選擇匯出格式
會彈出下拉選單，顯示兩個選項：
- 📗 **匯出 Excel (CSV)** - 適合數據分析
- 📄 **匯出完整報告 (HTML)** - 含統計圖表，可列印

### 步驟 4：自動下載
點擊後會立即下載檔案到您的下載資料夾

---

## 💡 使用技巧

### Excel (CSV) 匯出後的操作
1. 用 Excel 開啟 CSV 檔案
2. 可以使用篩選功能查看特定部門的提案
3. 建立樞紐分析表統計各等級的數量
4. 計算平均獎勵金額
5. 製作圖表視覺化

### HTML 報告的操作
1. 用瀏覽器開啟 HTML 檔案
2. 按 `Ctrl + P` (Windows) 或 `Cmd + P` (Mac) 列印
3. 可選擇「另存為 PDF」製作 PDF 報告
4. 直接用 Email 分享給主管或同事
5. 在會議中展示

## 🔧 技術實作細節

### CSV 匯出
- 使用 JavaScript Blob API
- UTF-8 with BOM 編碼確保中文正確顯示
- 特殊字元使用雙引號包裹並轉義
- 動態生成檔名包含當前日期

### HTML 匯出
- 純 HTML + CSS，無外部依賴
- 響應式設計，支援列印
- 使用字串拼接避免模板字串衝突
- 內嵌樣式確保離線可用

---

## ⚠️ 注意事項

1. **檔案位置**：匯出的檔案會儲存在瀏覽器預設的下載資料夾
2. **相容性**：支援所有現代瀏覽器（Chrome, Firefox, Edge, Safari）
3. **資料即時性**：匯出的是當前頁面顯示的數據
4. **中文支援**：CSV 檔案使用 UTF-8 BOM 編碼，確保在 Excel 中正確顯示中文

## 📌 常見問題

**Q: CSV 檔案在 Excel 中顯示亂碼？**
A: 確保使用 Excel 2016 以上版本開啟，或使用「資料」→「從文字檔」匯入時選擇 UTF-8 編碼。

**Q: 可以匯出特定部門的提案嗎？**
A: 目前匯出全部提案，但您可以在 Excel 中使用篩選功能。

**Q: HTML 報告可以修改嗎？**
A: 可以！下載的 HTML 檔案可以用任何文字編輯器開啟並修改樣式。

**Q: 如何自動列印 HTML 報告？**
A: 在 HTML 檔案中取消註解 `window.print();` 這行程式碼即可。
